## Objective

Separate Docker PostgreSQL configuration from the application's normal `.env` file.

Use:

```text
.env
.env.example

.env.docker
.env.docker.example
```

### Intended Responsibility

`.env`

* application/runtime configuration
* `NODE_ENV`
* `PORT`
* `HOST`
* `DATABASE_URL`

`.env.docker`

* Docker PostgreSQL container configuration
* `POSTGRES_DB`
* `POSTGRES_USER`
* `POSTGRES_PASSWORD`

`.env.example`

* safe application configuration template
* no real credentials

`.env.docker.example`

* safe Docker PostgreSQL configuration template
* no real credentials

The resulting service should conceptually be:

```yaml

  postgres:
    image: postgres:17-alpine
    ports:
      - "5433:5432"
    env_file:
      - .env.docker
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test:
        [
          "CMD-SHELL",
          "pg_isready -U \"$${POSTGRES_USER}\" -d \"$${POSTGRES_DB}\"",
        ]
      interval: 5s
      timeout: 5s
      retries: 5

volumes:
  postgres_data:
```

Do not unnecessarily change other Compose configuration.
